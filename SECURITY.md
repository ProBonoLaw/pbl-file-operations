# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting for this repository ("Security" tab, then "Report a
vulnerability"). If that is unavailable, email info@daatphoenix.com.
Include the affected component, a description of the impact, and steps to
reproduce. Do not include real client documents or credentials in
a report; use synthetic data.

We aim to acknowledge reports within a few business days. This project is
maintained by volunteers, so fix timelines are best effort.

## Supported versions

Only the latest commit on `main` is supported.

## Handling of sensitive data

This repository must never contain credentials, deployment identifiers, or
documents from real legal matters. If you find any, report it privately as
described above so it can be removed and, where needed, rotated.
